# ✨ Beleza Real

Site moderno e responsivo desenvolvido para um salão de beleza e cabeleireiro, com foco em apresentar serviços, trabalhos realizados e facilitar o contato e agendamento de clientes.

## 📋 Sobre o projeto

O **Beleza Real** é um projeto web criado para proporcionar uma experiência moderna, elegante e intuitiva para clientes que desejam conhecer os serviços oferecidos pelo salão.

O site reúne informações sobre os serviços, profissionais, galeria de trabalhos e formas de contato em uma interface agradável e adaptada para diferentes dispositivos.

## 🚀 Funcionalidades

* 🏠 Página inicial
* 💇‍♀️ Apresentação dos serviços
* ✂️ Informações sobre os profissionais
* 🖼️ Galeria de trabalhos
* 📅 Agendamento de horários
* 📞 Informações de contato
* 📍 Localização do salão
* 📱 Design responsivo
* 📲 Integração com redes sociais
* ✨ Interface moderna e intuitiva

## 🎯 Objetivo

O objetivo do **Beleza Real** é criar uma presença digital profissional para um salão de beleza, permitindo que os clientes conheçam os serviços, visualizem trabalhos realizados e entrem em contato de forma rápida e prática.
